# IBM decNumber 3.68

Source: https://speleotrove.com/decimal/decNumber-icu-368.zip

Only decNumber, decContext, their headers and upstream licensing/readme are
included. Sources are unmodified. All translation units must use
`DECNUMDIGITS=40`; the firmware wrapper defines the same storage capacity.
The calculator uses 23 significant digits for stored numerical results and
40 digits for intermediate work. See ICU-license.html for redistribution terms.
